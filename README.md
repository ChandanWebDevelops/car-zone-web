#  AutoMarket - Django E-commerce Car Dealership

A fully functional e-commerce platform for buying and selling cars, built with Django and Bootstrap 5.

## ✨ Features

- **User Authentication**: Register, login, logout, and profile management
- **Product Catalog**: Browse cars with detailed specifications, images, and filters
- **Shopping Cart**: Session-based cart with add/remove functionality
- **Checkout System**: Secure payment processing with Stripe integration
- **Order Management**: Track order history and payment status
- **Admin Dashboard**: Full-featured Django admin for managing inventory and orders
- **Responsive Design**: Mobile-friendly UI built with Bootstrap 5

## ️ Tech Stack

- **Backend**: Django 6.0.7, Python 3.13
- **Frontend**: Bootstrap 5, HTML5, CSS3
- **Database**: SQLite (development)
- **Payment**: Stripe API (Test Mode)
- **Images**: Font Awesome icons, Pillow for image handling
